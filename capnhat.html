Cập nhật ngay

Apps Script đọc dữ liệu mới nhất từ Google Sheets rồi ghi data.json lên GitHub. GitHub Pages thường phát hành bản mới sau 30–90 giây.

    Chưa cài mã GitHub? Cập nhật thủ công

    Tải bản data.json mới nhất từ Google Sheets về máy, rồi tải lên kho GitHub: mở kho → Add file → Upload files → kéo file data.json vào → Commit changes.

    Cài đặt lần đầu (một lần duy nhất)

    Để Apps Script tự ghi được data.json lên GitHub, cần một “mã truy cập” GitHub chỉ có quyền ghi vào kho này.

    Xem các bước
    1. Trên GitHub: ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Đặt tên (vd: data-json), Expiration tùy chọn; Repository access: Only select repositories → chọn kho của trang này.
    3. Permissions → Repository permissions → Contents: chọn Read and write → Generate token → sao chép mã (bắt đầu bằng github_pat_).
    4. Mở Google Sheet → menu 🥋 Thi thăng đai → Cài đặt cập nhật data.json (GitHub) → nhập tên kho, nhánh (main) và dán mã. Google sẽ hỏi quyền “kết nối tới dịch vụ bên ngoài” → Cho phép.
    5. Xong! Từ giờ sau mỗi lần sửa trên trang kế hoạch, data.json tự cập nhật sau ~20 giây; trang này dùng khi muốn cập nhật ngay (ví dụ sau khi sửa trực tiếp trong Google Sheets).

    Lưu ý: data.json nằm trong kho GitHub công khai, ai cũng xem được (giống như trang web). Đừng ghi số điện thoại hay thông tin riêng tư vào kế hoạch.
